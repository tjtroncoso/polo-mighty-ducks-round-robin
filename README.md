# Tennis Round Robin Generator

Create round robin schedules for tennis groups, clubs, and social play. Supports rotating doubles partners, mixed doubles, optional singles courts, timed or one-set rounds, late arrivals, custom court numbers, and copyable schedules.

Ready-to-deploy Vite + React app.

## Local test

```bash
npm install
npm run dev
```

## Vercel

Framework: Vite
Build command: npm run build
Output directory: dist
